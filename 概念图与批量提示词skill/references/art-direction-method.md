# 美术方向方法：先定设计目标，再制造可控差异

这是审美知识，不绑定任何生图模型。写 PROMPTS.md 的 A 节时照这个顺序思考。

## 1. 设计目标先于画面
- 先写一句话目标（叙事核心），再写画面必须让玩家一眼看清的东西。动作游戏一般是：**主角在哪、危险在哪、往哪打**。
- 判断一张图：设计目标 → 可读性 → 签名设计 → 是否落入俗套 → 最后才看好不好看。

## 2. 理解元素的表达功能，而不是模仿画面
研究参考作品时问「它为什么这样做」，把答案写成表格：

| 元素 | 常见表达功能 |
|---|---|
| 低饱和、冷灰 | 抽掉颜色等于抽掉生气，画面变冷变静，让人紧张；颜色变成稀缺资源，一出现就是信号 |
| 一抹高饱和色（常是红） | 人眼对它最敏感，满屏灰里一点红立刻被看到；红自带「血」和「危险」的含义，不用解释 |
| 破败的环境 | 建筑代表秩序。剥落、断裂、被异物侵入，说明维护它的人不在了，衰落不必说出口 |
| 雨、雾 | 压暗压冷；湿地面给暗场景少量反光层次；雨丝给静止画面持续的动感 |
| 留白、边缘晕开 | 观者补全，更有意境；把视线推回中心；顺便藏住生成图和低模的瑕疵 |
| 遮脸 | 看不清脸的人更像符号，玩家通过他做什么来认识他 |
| 两种材质冲突 | 材质冲突就是世界观冲突（例：木石墨 vs 黄铜管道 = 旧江湖 vs 新势力） |

## 3. 主动列出俗套
AI 对一个题材会反复给出同一组元素：单张都好看，但作品之间分不开，还会稀释信号色。开工前把它们列出来写进负面词。

## 4. 可控差异（签名设计）
- 每个主要资产只做 1–2 个非标准设计，每个都要回答「它表达什么」。
- 写清楚控制手段，让它不和功能冲突。例：同样是红色，**信号红**是亮的、发光的、会动的，**地标红**是暗的（明度约一半）、哑光、不动、不进战斗区。
- 小特征要放大到游戏镜头里看得见（俯视下帽檐缺口要大到约 1/6 圆周）。
- 先用一张验证图确认差异成立，再批量。

## 5. 不要在同一张图上解决所有问题
签名设计在氛围图里画不出来时，放到角色资产包和 3D 阶段去补，不要反复重生锚点。
